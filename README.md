# SkillBoost - Adaptive Testing & Personalized Career Guidance

SkillBoost is an AI-powered web application that helps users identify suitable IT career paths through adaptive skill assessment and personalized recommendations.

The platform dynamically adjusts question difficulty based on user performance, evaluates technical skills, and recommends the most relevant career roles using Natural Language Processing (NLP) techniques.

## Features

- 🔐 User Authentication
- 🧠 Adaptive Skill Assessment
- 🤖 Automatic Question Generation
- 🎯 AI-Based Career Recommendation System
- 📊 Performance Tracking Dashboard
- 📈 Personalized Learning & Career Guidance

## Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite
- **Machine Learning:** CountVectorizer, Cosine Similarity
- **Data Processing:** Feature Engineering, PCA, Label Encoding, One-Hot Encoding

## How It Works

1. User registers and logs in.
2. Takes an adaptive skill assessment.
3. Question difficulty changes according to performance.
4. The system analyzes the user's skills using NLP techniques.
5. Suitable IT career roles are recommended along with skill-gap insights.
